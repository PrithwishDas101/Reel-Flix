# Reel-Flix

Reel-Flix is a React movie-discovery frontend built with React 19, Vite, and React Router. The project is organized around reusable UI components, shared context, and page styling.

## Features

- React single-page application with client-side routing
- Component-based UI architecture
- Shared application state through React context
- Dedicated styling under `src/css`
- Vite-powered local development and production builds

> This repository currently documents the frontend codebase. Do not assume that authentication, a custom backend, streaming playback, or a movie-data API is configured unless those integrations are added to the source.

## Tech stack

- React 19
- Vite 8
- React Router 7
- JavaScript (ES modules)
- ESLint

## Getting started

Requirements: a Node.js version compatible with the Vite version in `Frontend/package.json`, plus npm.

```bash
git clone https://github.com/PrithwishDas101/Reel-Flix.git
cd Reel-Flix/Frontend
npm install
npm run dev
```

Open the local URL printed by Vite in your terminal.

## Scripts

Run these from `Frontend/`.

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Build the app for production |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |

## Project structure

```text
Reel-Flix/
└── Frontend/
    ├── package.json
    └── src/
        ├── App.jsx
        ├── main.jsx
        ├── components/
        ├── contexts/
        └── css/
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated by Vite. Configure your hosting provider to serve the built frontend and support client-side route fallbacks if you deploy routes beyond the root path.
